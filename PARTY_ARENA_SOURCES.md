# Party knights and dungeon arena — original Dungeon Crawl tiles

Original artist-made pixel art by Dungeon Crawl Stone Soup / RLTiles contributors. Source: https://github.com/crawl/crawl . Pinned historical revision: 7c9bbd012c6538499643b2da006c16a7c6fee1e0, 17 September 2016. This source predates generative-image tools. No AI imagery or synthesized sprite frames were used.

The silver Vault Guard represents Vesper, the dark Death Knight represents Rook, and the red-and-gold Vault Warden represents Wren. This is a cosmetic selection, with no stat, class, item or team changes. Original 32×32 PNG files are copied unchanged. Gameplay movement, attack lunge, recoil and death motion animate these original stills; no invented frame sequence is claimed.

Three original cobblestone floors and a dark masonry wall replace the earlier flat dungeon floor tiles. Floor filenames include `cobble_blood`; the selected originals are retained exactly, with their hashes in SELECTIONS.json. Runtime lighting and grid / danger / target overlays are separate rendering. Decorative masonry lies outside the legal nine-by-nine board and never changes occupied tiles or paths.

The original tile-directory licence identifies RLTiles art as public domain. The upstream licence distinguishes tile artwork (Public Domain / CC0) from GPL program code. Both notices are retained here. Only selected PNG artwork is used; no Dungeon Crawl program code is copied. SELECTIONS.json records every original path, pinned URL and SHA-256. The Hollow keeps its existing pinned original tile.

Additional licence verification: all seven PNGs match exact Git blob hashes in crawl/tiles, the upstream repository specifically curated for CC0 reuse (Nov-2015 release). SELECTIONS.json records the curated repository revision, original release paths and blob IDs. Original curation README, artist approvals and excluded-tile list are retained here. None of the selected images is on the exclusion list. Masonry uses the original gray-brick tile.
