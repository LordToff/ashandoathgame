# Ash & Oath v0.44 — test chamber and ash-and-brass menus

15 November 2026. Browser release; existing Windows downloads are unchanged.

- Test chamber is a fixed main-menu button on desktop and mobile, with no More submenu required. It opens the ability picker directly.
- Shared chamber tools provide search by ability name / effect, all 73 normal and earned face entries, forced Numeric 0 / 1 / 2 or random, reset, enemy attacks, turn advance, repeat rolls, combinations, log copying and boss phase II.
- During practice, desktop Test tools or phone More → Test tools reopens the controls. Mobile combination setup is now reachable too. Searching is read-only; selecting or resetting intentionally prepares a fresh scenario. Practice never spends normal inventory or grants encounter rewards.
- Shared menus now show the existing chamber artwork, a drawn oath seal, ash flecks, brass dividers / borders, distinct emblems and serif card headings. The desktop main menu includes an oathfire scene with the existing hero sprites; main actions have stronger frames. Backgrounds and decoration ignore input and use no combat RNG or timer.
- Fixed Back / Next controls, equipment previews, paid reward validation and four-slot rules retain their behavior.

No replacement enemy sprites or new generated artwork are included. See Validation-v0.44.md for checked layouts and limitations.
