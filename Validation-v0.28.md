# v0.28 validation

Godot 4.6.3 official Linux engine with its matching Web templates. **29 scripts passed, 8,159 checks**, including 55 focused v0.28 checks and 115 Essence checks. Per-script results are in [Validation-v0.28.json](Validation-v0.28.json).

The focused suite checks Dagger ownership/equip persistence, body requirements, first positive enemy HP damage, blocked/friendly/other-actor exclusions, adjacency, no die/reroll cost, once-per-turn/reset rules, pending/forced/Shared Burden restrictions, Weakness/Block/Warden armor/Veyl Resonance, enemy-minion damage, actual menu navigation, direct fight routing/banking, all four equipment selectors, valid/invalid Forge replacements, Beginning Soul migration/Move 1/one-use/refresh/per-hero scope, and bounded item-sprite regions. Existing combat, ownership, Soul, loadout, catalog, boss, Poison and event suites pass. Historical UI assertions were updated for intentional main-menu, tab and roll-presentation changes; they were not disabled.

Two real exported Chromium verifiers pass with no console or page errors. Normal flow covers main menu, party selection into direct Swift Pack, individual creature cards, return to menu, equipment dropdowns and reload persistence, Forge, reroll timing options and a genuinely rolled mixed event. A separate local fixture exercises actual death/outcome banking, no duplicate claims, hidden recipes, same-cost duplicate crafting, legal refitting, Memory craft/equip/healing, Shared Burden source/recipient/return, hostile and friendly Evasive, defeat preserving the previous bank, owned item art, Dagger’s target/HP/die state and spent use, and Beginning Soul movement/second-Blank restriction.

The fixtures are generated in a separate project by tools/make_essence_fixture.py. Its GDScript and browser callbacks live under tools, which the shipping export excludes. Browser screenshots/results are generated in ignored exports/hub-browser and exports/essence-browser. Animations present model-recorded results and were visually inspected; this is not a guarantee of frame rate on every browser/device.

Some native UI processes retain the previous ObjectDB/resource warnings on shutdown. No script errors occurred in the passing suites. These tests are not human balance trials or a full manually played campaign. Creature stats/AI/group composition and Dagger starter/once-per-turn/no-die choices remain provisional. Windows artifacts were not rebuilt.
