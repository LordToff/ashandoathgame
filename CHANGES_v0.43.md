# Ash & Oath v0.43 — clearer menus in both modes

15 November 2026. Browser release; Windows downloads retain their previous version.

- Main menu explains Normal adventure and Trials, their routes and separate rewards. Practice and advanced tools live under More.
- Normal party preparation offers legal suggestions for remaining heroes, ability explanations and optional custom bonuses / individual die editing. Existing ready heroes stay unchanged. Boss choice hides optional advanced rules; road choices explain actual costs and possible rewards.
- Camp separates Craft upgrades, Install abilities, Equip gear and Fight creatures. Recipes show cost, missing materials and owned / allocated / available face counts. A successful craft links to its installation or gear slot.
- Equipment is previewed one hero and one slot at a time. Apply is explicit. Incompatible gear can offer a clearly labelled starter-dice rebuild; crafted copies stay owned. Installation previews one die side before applying; returning a crafted face keeps its physical copy.
- Trial victory rewards now choose recipient → reward type → preview → die side if needed → purchase. Memory rewards show the Memory choice without an unrelated dice grid. Back / Help spend nothing.
- Shared context Help has searchable explanations for four equipment slots, abilities, combat terms, supplies and the three separate Essence balances. Closing it returns to the same screen and choice. Escape closes Help alone.
- Shared headers reserve title / Help space and measure wrapped text. Footers keep Back / Next / Apply visible on desktop, portrait and landscape. Selectors fit narrow widths without pushing the menu sideways and open on release so a scroll can cancel them. Audio widgets no longer cover the shared footer.

Equipment limits, owned rewards, costs, battle rules, direct combat inputs and RNG retain their existing semantics. Both normal and Trial collections remain separate. No new art or Windows build is included.

See Validation-v0.43.md and the regenerated current rulebook for verified flows and limitations.
