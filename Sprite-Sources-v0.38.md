The game selects existing 16×16 tiles. Some spirit/enemy variants use explicit palette substitutions. No image generation service or synthesis is used. The build script documents each selected tile and palette change. Kenney's original sheet is kept intact for attribution and reproduction.

The v0.36 ritual stones, spirit and boss core use flat pixel geometry drawn directly in prototype/prototype.gd; no new external image assets were added.

v0.37 adds class setup UI and uses the existing character sprites; no new external image assets were added.

v0.38 adds Soulcaster and Trial help UI using existing sprites; no new external image assets were added.
