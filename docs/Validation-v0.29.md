# v0.29 validation

New tests cover enemy HP and printed dice, individual new Essence tokens and idempotent banking, hidden Soul designs, exact per-recipient crafting cost and ownership, same-hero duplicate rejection, other-hero purchases, no mixing currencies, equipment and save roundtrip. Soul checks exercise actual healing and full-HP refusal, Downed-owner restriction, Memory interaction and actual-result logging, Block/expiry/modifiers, blink range and crossing occupied cells, empty landing/Rooted, per-own-turn limits/refresh, inert extra Blanks and Shared Burden restrictions. Enemy checks exercise actual/blocked/reacted Venom Bite, range-three Needle and line of sight, Husk Bash/Guard and distinct movement budgets. Native UI checks cover pagination, recipient crafting, scoped equipment, item art and all three new encounter launchers.

The saved Essence, equipment and new Wilds Chromium verifiers pass without console/page errors. Normal exported UI checks include the Wilds page and artwork, party preparation into a real Leech group, public dice, the old required-event/boss route and inventory/equipment saving. A separate deterministic project exercises paid Soul binding to Rook, ownership, equipment/sprite selection, actual Mire healing and once-per-turn restriction, Ironbound Block and Glasswing blink through the real controls. The existing suite also covers crafting/refitting, Memory, Shared Burden, hostile/friendly Evasive and old-bank safety after defeat.

Screenshots/results are written to ignored exports/wilds-browser, exports/essence-browser and exports/hub-browser. Fixture callbacks exist only in the separate project generated by tools/make_essence_fixture.py; the shipping export excludes tools and tests. No stale assertions were disabled; the ordinary-creature tooltip retains its explicit not-a-summon description.

Some native UI processes retain existing ObjectDB/resource warnings at shutdown. No script errors occurred in the passing suites. These are implementation regressions, not full human balance trials or proof of fair win rates. HP, dice weights, encounter composition and Soul costs/effects are provisional. Windows artifacts remain unchanged.

Release package revision 2 includes explicit regressions that Weakness reduces a lead Husk Bash exactly once and that a weakened lead Leech cannot inflict Poison through a zero-damage bite. The minion and lead paths apply the same modifier once.
