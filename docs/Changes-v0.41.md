# Ash & Oath v0.41 — See the roll, feel the hit

14 November 2026

- Restored the earlier Nu’gh, worms, mites, cocoon and familiar creature pixel sprites; Wilds return to the existing Kenney selections. Other bosses / Trial roles retain their licensed 0x72 art. Camp portraits match combat.
- Replaced screen-filling roll overlays with compact panels. Dice settle over 0.8 seconds and keep their actual outcome visible for 1.3 seconds; ability buttons, the last-roll strip and full history retain results afterward.
- Sequenced recorded rolls, readable results, attack wind-up / lunge, impact and status cues. HP and Block change visibly at impact. Worms lunge with a jaw effect; misses show zero and no Poison. Stronger recoil, Poison smoke / pulses and matching sounds make results easier to follow. Poison ticks have no text popup.
- Combat calculations and RNG still resolve once. Playback never rerolls or reapplies damage; controls, required choices and outcomes wait for their animation sequence.
- Replaced the permanent combat log column with a Battle log button opening Summary / Extensive history. Wider desktop ability controls and explicit Details, viewport-sized phone text, fixed combat controls, and a clean single 9×9 grid fix crowding and misleading board lines.
- Added Settings → Blank → Move 1, OFF by default and persisted on this device. In both modes, spend one rolled Blank for Move 1 once per hero turn. Invalid moves spend nothing; OFF / ON does not refill a spent use. Soulcaster keeps Gather / Manifest and gets a separate Move 1 option while enabled.
- Retained both modes' Body / Soul / Memory / Weapon definitions, die ownership, rewards and saved collections. Regenerated the current rulebook as HTML / Markdown / PDF.

Browser release only; Windows downloads remain their existing versions. Browser saves stay local to this browser/device.
