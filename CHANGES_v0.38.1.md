# Ash & Oath v0.38.1 — fullscreen Settings

13 November 2026.

- **Options → Fullscreen** uses the whole screen in desktop, mobile and Trial Settings.
- The same button becomes **Exit fullscreen** while active. Desktop browsers also support **Esc**.
- The caption follows actual browser state, including exits through browser controls. The existing layout adapts when the available screen space changes.
- Browsers without a fullscreen API show an unavailable button.

This is a presentation update. The v0.38 gameplay rules/PDF remain current. Windows artifacts were not rebuilt.
