# Ash & Oath v0.41

[Play in your browser](https://lordtoff.github.io/ashandoathgame/?v=0.41)

Restored Nu’gh and creature art. Compact readable dice, a clear roll → wind-up → impact → status sequence, stronger attack / Poison effects and matching sounds. Wider combat controls, a single board grid and a log button free up space. Settings adds optional Blank → Move 1 in both modes.
