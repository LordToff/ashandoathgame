# Ash & Oath v0.33

[Play in your browser](https://lordtoff.github.io/ashandoathgame/?v=0.33)

Fixed mobile combat controls, simple colored ability names, tappable enemy intents and visible Block, Poison smoke/sound without popups, four boss ability/Memory rewards, and optional long-hold Debug unlocks. Mobile mode supports portrait and landscape. Saved banks and old creature prices are preserved.

[Changes](CHANGES_v0.33.md) · [Validation](Validation-v0.33.md) · [Rules](current-rules.html) · [PDF](AshAndOath-Current-Rules-v0.33.pdf)

Browser checks cover 390×844, 360×640, 844×390 and desktop 1440×900. Physical phone hardware and Windows downloads were not tested/rebuilt. Difficulty remains provisional. Sprites remain human-authored Kenney CC0 pixel art.
