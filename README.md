# Ash & Oath v0.30

[Play in your browser](https://lordtoff.github.io/ashandoathgame/?v=0.30)

The detailed generated enemy/Soul art is replaced with human-authored Kenney Tiny Dungeon CC0 pixel sprites: native 16×16 tiles, explicit palette variants, hard pixel edges and integer enlargement. Six Souls, Memory of Loss and the three Wilds creatures use the replacements. Gameplay, prices, equipment, ownership and saves remain unchanged.
