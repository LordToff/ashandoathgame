# Ash & Oath v0.37

[Play in your browser](https://lordtoff.github.io/ashandoathgame/?v=0.37)

Main menu → **Trials** now offers two classes per hero: Skirmisher (Spear, Fleet Body, Memory of Momentum) and Vanguard (Hammer, Stone Body, Memory of Guard). Free starting kits include Beginning Soul and legal starter dice with rolled Jab / Crack replacing one Strike. Tap the class card for every face, HP details and an example turn. Normal Camp and encounters keep their rules and inventory.
