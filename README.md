# Ash & Oath v0.40

[Play in your browser](https://lordtoff.github.io/ashandoathgame/?v=0.40)

Normal play and Trials now share the corrected Body / Soul / Memory / Weapon rules. Bodies set Defense, Movement and Skill ranges. Souls set HP, required Blanks and a strong effect. Memories start empty. Weapons set Attack limits, replace 1–3 basic Strikes and may modify all Attack faces.

This browser release preserves the existing Windows downloads without rebuilding them.
