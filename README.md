# Ash & Oath v0.39

[Play in your browser](https://lordtoff.github.io/ashandoathgame/?v=0.39)

**Attack → map target. Movement → destination. Guard / self effects → one tap.** No extra generic Trial confirmation. Soulcaster uses a compact, board-visible **Blank → Gather or spell** panel with visible costs and optional Help.

Enemy sprites now use original animated **0x72 DungeonTileset II** pixel art, CC0 and explicitly marked non-AI by the artist. Distinct Trial roles, four bosses, ordinary creatures and summons use real idle/run frames. Stats and legal footprints keep their rules. Fullscreen remains in Options.
